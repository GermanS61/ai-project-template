# SECURITY

## Базовые правила

- не коммить secrets, tokens, `.env`, private keys и production credentials;
- используйте `.env.example` только с безопасными placeholders;
- секреты должны храниться в secret manager / GitHub Secrets / другом утверждённом механизме;
- перед разрушительными изменениями данных или инфраструктуры должен существовать rollback/backup plan;
- минимизируйте права внешних integrations.
